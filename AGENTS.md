# Project agent instructions

## Read by task

The local `docs/` directory is optional in a source checkout. Read the applicable guides when
available. Use [GLOSSARY.md](GLOSSARY.md) for domain terms and [README.md](README.md) for the demo
and build entry points.

- Before domain exploration or implementation, read `docs/agents/domain.md`, then the relevant
  requirements in `docs/SPECIFICATION.md` and decisions in `docs/adr/`.
- For implementation, debugging or validation, read `docs/agents/development.md`.
- For the `config.yml` server layout, read `docs/QUICKSTART.md`. For the separate `compose.yaml`
  host-profile layout, read `docs/DOCKER-DEPLOYMENT.md`.
- For backup or restore work, read `docs/BACKUP-RESTORE.md`.
- For native builds, client upgrades or source delivery, read `docs/BUILDING.md`.
- For PDF/font changes, read `docs/report-font.md`. For complaint-category changes, read
  `docs/reference-complaints.md`.

## Local tracker

Track specs and tickets under ignored `.scratch/`. When the guides are available, read
`docs/agents/issue-tracker.md` for ticket changes and `docs/agents/triage-labels.md` for status changes.
